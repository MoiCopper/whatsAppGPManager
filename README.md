# WhatsApp GP Manager

Aplicação Node.js com TypeScript para gerenciar grupos do WhatsApp usando whatsapp-web.js.

## Instalação

```bash
npm install
```

## Execução

Para executar em modo desenvolvimento com hot reload:

```bash
npm run dev
```

Para build e execução em produção:

```bash
npm run build
npm start
```

## Configuração

1. Execute `npm run dev`
2. Escaneie o QR code exibido no terminal com seu WhatsApp
3. Aguarde a mensagem "Client is ready!"

## Funcionalidades

- Responde "pong" quando recebe a mensagem "!ping"
